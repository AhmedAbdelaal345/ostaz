# مراجعة الاتساق البصري

تمت مراجعة الشريط العلوي والصفحة الرئيسية والإعدادات والبطاقات الأساسية. أزيل العنوان الفرعي الزائد من أعلى الصفحة، ووحّدت الإعدادات في قائمة رأسية ذات حالة نشطة واحدة، مع تباعد ثابت وحواف موحدة وحالة hover/focus واضحة. كما تم تقليل كثافة الأزرار داخل الإعدادات، وتوحيد ارتفاع عناصر القائمة، وإضافة استجابة خاصة للشاشات الصغيرة حتى لا تتكدس العناوين أو الحقول.

تظل كل أقسام الإعدادات مرتبطة بحالة `tab` واحدة؛ لذلك عند اختيار قسم جديد يُغلق القسم السابق تلقائيًا ويظهر محتوى القسم المحدد فقط. تم الحفاظ على الهوية الداكنة والألوان الزرقاء التشغيلية دون إضافة عناصر زخرفية غير ضرورية.
