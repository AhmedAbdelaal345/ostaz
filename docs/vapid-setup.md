# إعداد مفاتيح Push الخلفية

يولّد السكربت المحلي مفاتيح **VAPID** عبر الأمر التالي:

```bash
pnpm vapid:generate
```

يعرض الأمر المفتاح العام والمفتاح الخاص وبيان تعريف افتراضي. لا يكتب السكربت أسرارًا داخل `.env` أو داخل ملفات النشر. تُنقل القيم إلى إعدادات البيئة الآمنة للمشروع فقط، ثم يستخدم الخادم المفتاح الخاص لإرسال Push ويستخدم المتصفح المفتاح العام للاشتراك.

غيّر `VAPID_SUBJECT` إلى بريد مسؤول صالح قبل النشر النهائي.
